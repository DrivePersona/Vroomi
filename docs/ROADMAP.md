우선순위는 사용자가 정한다. 아래는 현재 근거에서 본 추천 순서다.

| 작업 | 이유 | 규모 |
| --- | --- | --- |
| **줄별 몸짓 선택 + 크로스페이드** | 지금은 신호당 클립 1개라 대사 12줄이 몸짓 4개를 나눠 쓴다. 이미 만든 클립도 못 부른다. 설계: [ANIMATION_AND_ACTING](ANIMATION_AND_ACTING.md) 5절 | 중 (5a→5b→5c) |
| 신호 반응 확대의 대사 음성화 | 신호 대사 15줄은 기본 음성이 읽는다. 캐릭터 목소리로 읽으려면 비공개 음성 팩에 슬롯·클립이 필요하다 | 콘텐츠 + 계약 변경 |
| 상태줄 개선 | 서비스가 조용히 거절하는 구독(드라이브 모드 등)이 "구독 요청"으로만 보인다. 구독별 첫 값 수신 여부 표시 | 소 |

## 4. Pleos에 확인할 것

보낼 질문 목록. 아직 보내지 않았다. 초안은 [PLEOS_PLATFORM_FINDINGS](PLEOS_PLATFORM_FINDINGS.md) 9절에 모았다.

1. 서드파티 차량 앱의 `SYSTEM_ALERT_WINDOW` 오버레이 허용 여부와 범위
2. 포그라운드 서비스, 부팅 시 자동 시작 허용 여부
3. 서드파티 앱용 오디오 컨텍스트·오디오 존 (현재 `USAGE_MEDIA`로 가정)
4. `setSpeakerType` 유효 값, 온디바이스 음성 목록, 선행 묵음(150ms) 가이드의 SDK 경로 적용
5. 새 권한 승인 범위 (창문·도어·공조 등), 형제 선언 이름 불일치 확인 (`READ_WINDSHIELD_WIPERS` 등)
6. 오버레이를 가려도 되는 화면 영역 (끌어서 이동 범위)

## 5. 프로토타입 계보에서 발견된 문제 — main에서 재확인 필요

초기 프로토타입(Phase 2~4b 계보)에서 확인한 결함이다. `main`은 코드가 크게 달라졌으므로 **같은 증상이 남아 있는지 먼저 재현한다.** 확인 전에는 `main`의 결함으로 단정하지 않는다.

| 증상 | 당시 원인 | 재확인 방법 |
| --- | --- | --- |
| 새로 설치한 기기에서 VR을 켜는 화면 조작이 없어 오버레이로 가는 길이 없음 | 기본값 꺼짐 + 켜는 UI 없음 | `pm clear` 뒤 첫 실행에서 오버레이 시작 가능한지 |
| VR 시작으로 설정 화면을 닫고 주행하면 오버레이가 사라지고 프로세스가 얼어 신호를 못 받음 | 화면 없는 상태에서 프로세스 우선순위 하락 | 포그라운드 서비스 호스팅(`CompanionService`)으로 해결했으나 이 계보에서만 확인. `main`에서 같은 시나리오 반복 |
| 폭 720dp 미만(폰)에서는 캐릭터 고르기·VR 시작이 화면에 없음 | 넓은 화면 전용 구성 | 폰 폭 에뮬레이터에서 확인 |
| `POST_NOTIFICATIONS` 미선언으로 포그라운드 서비스 알림이 안 보일 수 있음 | 안드로이드 13+ | 알림 표시 확인 |
| 안드로이드 TTS 엔진 연결이 끊기면 다시 붙지 않음(폰 경로) | 재연결 코드 없음 | Pleos 경로는 Pleos TTS SDK라 해당 없음 |
| Pleos 에뮬레이터에서 스킨 있는 GLB가 오버레이에 그려지지 않고 컨셉 이미지만 보임(단순 GLB는 정상) | 원인 미확인 (스킨·텍스처 GLB 전반으로 추정) | 해당 에뮬레이터·GPU에서 재현 |
| `EVS`(측면 카메라) 화면이 뜨면 오버레이가 가려지고 사라짐 | 셸 동작 | Pleos 문의 |

## 6. 하지 않기로 한 것

- 런타임 임의 문장 합성(자체 TTS 모델 팩): 라이선스·품질·크기·성능 게이트를 통과하기 전에는 보류. 대사는 사전 제작 클립이다.
- 팩 다운로드·마켓·이벤트별 다른 팩·서버 합성: v1 범위 밖.
- 기존 캐릭터·성우 목소리 사용: 기획 원칙상 금지.
- 연구용 모션 생성 모델을 라이선스 확인 전에 배포물에 넣는 것 ([RESEARCH_NOTES](RESEARCH_NOTES.md)).
