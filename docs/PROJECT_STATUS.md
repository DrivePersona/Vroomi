# 프로젝트 현황

**기준일:** 2026-11-12 · `main` a58f3e8(PR #43 머지) · 갱신형 문서

## 한 줄 요약

차량이 알려 주는 상태(브레이크·방향지시등·드라이브 모드·안전벨트, 외부등·기어·크루즈 등)를 사용자가 고른 캐릭터의 목소리와 몸짓으로 알려 주는 Pleos 차량 앱이다. 앱·시뮬레이터·차량 신호 수신·음성 재생·캐릭터 표시의 **뼈대는 에뮬레이터에서 동작**한다. **출시 가능한 콘텐츠(33개 캐릭터, 429개 음성)와 실차 검증은 아직 없다.**

## 구성

| 저장소 | 공개 | 역할 |
| --- | --- | --- |
| `Vroomi` | Public | 앱, 웹 시뮬레이터, 설계·검증 문서, 팩 연동 계약 |
| `voice-pack-sdk` | Private | 클립 재생 SDK, 캐릭터별 음성 팩 제작물, 음성 권리 메타데이터 |
| `character-pack-sdk` | Private | 캐릭터 GLB 검증·표시 SDK, 캐릭터 에셋, 애니메이션 |

앱은 두 SDK를 비공개 패키지(AAR)로 받는다. 빌드 변형은 `reviewDebug`(상업 에셋 없음, 공개 시연용)와 `internalRelease`(팀 전용, 비공개 AAR 포함)다.

## 지켜야 할 안전 규칙

- 주행 중에는 캐릭터를 숨기고 음성만. 차량 경고·안전벨트는 연출 없이 중립 음성, 몸짓 없음.
- 앱은 차량을 제어하지 않는다. 읽기 전용 구독만 한다.
- 오디오 포커스를 얻지 못하면 말하지 않고 쿨다운도 쓰지 않는다. 포커스를 잃으면 바로 멈춘다.
- 값이 실제로 오는지 확인되지 않은 신호(타이어 등)는 자동 반응에 연결하지 않는다.
- 선언한 Pleos 권한은 실제 쓰는 API의 것만. 현재 `CAR_DRIVE`·`CAR_LIGHTS`·`CAR_SAFETY`·`TTS_SERVICE`에 일반 권한 `SYSTEM_ALERT_WINDOW`.
