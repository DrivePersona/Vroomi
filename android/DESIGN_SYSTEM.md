# 보이스 컴패니언 디자인 시스템 v0.1

## 목적과 적용 범위

이 문서는 차량용 보이스 컴패니언의 Compose 화면을 위한 제품 디자인 계약이다.
색상과 인터랙션은 Pleos 차량 환경의 안전·가독성 원칙을 우선한다. 앱 화면(`CompanionTheme`)은 특정 금융 앱 또는 모바일 앱의 디자인 시스템을 색상 기준으로 쓰지 않는다.
**예외: 오버레이 시트와 플로팅 메뉴는 TDS(Toss Design System) 기준이다** — 아래 "오버레이 시트 — TDS 기준" 절을 따른다(프로젝트 결정, 2026-11-14).

시각 요소보다 차량 안전 규칙이 우선한다. Pleos의 주행 안전 원칙에 따라 주행 중에는 시각·인지 부담을 줄이고, 정차 중에만 개인화 기능을 제공한다.

## 제품 경험

| 상태 | 역할 | UI 원칙 |
| --- | --- | --- |
| 정차 | 내 차의 목소리와 캐릭터를 고르는 개인화 공간 | 팩 선택·대사 편집·미리듣기·VR 설정을 제공한다. |
| 주행 | 짧고 신뢰할 수 있는 음성 동반자 | 설정·캐릭터·CTA를 제거하고 음성 반응과 핵심 상태만 보여 준다. |

`CarUxRestrictions`가 항상 실제 주행 제약의 기준이다. 기어·속도를 자체 추측해 UI 정책을 바꾸지 않는다.

## 토큰

토큰은 `app/src/main/java/com/example/voicecompanion/ui/theme/CompanionTheme.kt`가 유일한 정의 위치다. 화면에서 색상이나 간격 수치를 직접 만들지 않는다.

- **기본 표면:** 주간은 `#F3F5F7` 캔버스·`#FFFFFF` 표면·`#18212B` 텍스트, 야간은 `#0E1218` 캔버스·`#171D25` 표면·`#F2F5F7` 텍스트를 사용한다.
- **개인화 포인트:** 저채도 바이올렛 `#5B4DB3`(야간 `#C9C2FF`)은 정차 중 팩 선택, VR 시작, 캐릭터 관련 상태에만 사용한다.
- **차량 의미 색상:** 위험·주의·규제·공조·운전자 보조 색상은 앱이 정의하거나 일반 CTA에 재사용하지 않는다. Pleos/OEM 시스템 토큰과 정책을 따른다.
- **라이트/다크:** 시스템 모드에 맞춰 각각의 `ColorScheme`을 제공한다. 한 모드의 값을 다른 모드에 그대로 재사용하지 않는다. 향후 차량의 주·야간 모드 API가 확정되면 시스템 다크 모드 대신 그 신호를 우선한다.
- **타이포그래피:** 시스템 산세리프를 사용한다. 제목은 `headlineSmall`/`titleMedium`, 본문은 `bodyLarge`/`bodyMedium`, 상태 라벨은 `labelMedium`을 쓴다.
- **간격과 모서리:** 페이지 20dp(좁은 화면 16dp), 섹션 20dp, 카드 20dp, 행 16dp, 버튼 14dp를 기본값으로 둔다.
- **터치 영역:** 조작 가능한 행·버튼의 최소 높이는 52dp다.

## 공통 컴포넌트

`ui/component/CompanionComponents.kt` 외부에서 개별 `Surface`, 기본 버튼의 시각 규칙을 새로 만들지 않는다.

| 컴포넌트 | 용도 |
| --- | --- |
| `CompanionCard` | 한 목적을 가진 정보·설정 블록 |
| `CompanionSectionHeader` | 짧은 제목과 한 줄 보조 설명 |
| `CompanionBadge` | 정차/주행 같은 짧은 상태 표현 |
| `CompanionListRow` | 팩처럼 하나를 고르는 선택 행 |
| `CompanionPrimaryButton` | 한 화면 또는 섹션의 핵심 행동 |
| `CompanionSecondaryButton` | 보조·되돌릴 수 있는 행동 |

## 콘텐츠와 상태 규칙

- 한 메시지는 가능하면 1~2줄, 최대 3줄로 끝낸다. 상태는 `현재 상태 + 가능한 다음 행동`으로 쓴다.
- 선택 불가 항목은 흐리게만 만들지 않고 이유를 함께 보인다.
- 색상만으로 성공·주의·비활성을 전달하지 않는다. 텍스트 상태를 병기한다.
- 주행 중에는 자동 스크롤, 장식적 모션, 반복 애니메이션을 사용하지 않는다.
- 주행 화면에는 설정 행·팩 선택·주요 CTA를 표시하지 않는다. 개발용 시뮬레이터는 debug 빌드에만 둔다.
- 캐릭터의 시각 반응은 정차 중 VR 오버레이에 한정한다. GLB 3D와 2D 스프라이트 모두 이 제약을 따르며, 안전 경고에는 캐릭터 연출을 붙이지 않는다.
- 모든 터치 조작은 한 손으로 가능한 짧은 행동이어야 한다. 긴 대사 입력·팝업 다단계 흐름은 정차 상태에서만 제공한다.

## 구현 경계

Compose Material 3는 렌더링 기반이다. 화면은 `CompanionTheme`과 `Companion*` 컴포넌트만 사용하며, 비즈니스 로직은 `ViewModel`과 `CompanionTouch`를 통해서만 호출한다. 새 화면을 만들 때는 먼저 이 문서에 필요한 토큰 또는 공통 컴포넌트를 추가한 뒤 화면에 적용한다.

## 오버레이 시트 — TDS 기준

정차 중 캐릭터 곁에 뜨는 플로팅 메뉴와 compact 시트 4종(캐릭터 바꾸기·가챠 보관함·캐릭터 대사·캐릭터 설정)은
[TDS Mobile](https://tossmini-docs.toss.im/tds-mobile/)을 기준으로 만든다. TDS는 React 계열 라이브러리라 그대로 쓰지 못해,
토큰과 컴포넌트 **구조**를 Compose로 옮겼다. 캐릭터(아바타) 자체의 표시는 이 절의 대상이 아니다.
정식 인증은 주장하지 않는다. 코드 위치는 `ui/theme/TdsTheme.kt`(토큰·테마)와 `ui/overlay/TdsOverlayComponents.kt`(컴포넌트)이다.

### 적용한 TDS 값 (출처: TDS 문서 그대로)

| 영역 | TDS 기준 | 앱에서 |
| --- | --- | --- |
| 색 | `foundation/colors`: grey50~900, blue50~900, red·green·orange 일부, `colors.background` #FFFFFF | `TdsColors`. 스위치 켜짐 트랙은 blue500, 주요 행동·강조는 blue700·blue800(아래 "대비" 참고), 표면은 흰색, 본문은 grey900, 보조는 grey600·grey700, 구분선은 grey200 |
| 글자 | `foundation/typography`: Typography 3(22/31), 4(20/29), 5(17/25.5), 6(15/22.5), 7(13/19.5) | 시트 제목 = Typography 4(`BottomSheet.Header`), 설명 = Typography 6(`HeaderDescription`), 행 제목 = Typography 5, 행 설명·버튼 = Typography 6, 안내 = Typography 7 |
| 시트 구조 | `BottomSheet`: header → headerDescription → children → cta | `TdsSheetHeader` → 스크롤 본문 → 아래 고정 CTA(가챠 시트의 "뽑기") |
| 행 | `ListRow`: left · contents · right, 세로 여백 medium 12, 가로 여백 small 20, 들여쓴 구분선, 비활성 type2(회색 배경) | `TdsListRow`, `TdsRowDivider`. 선택 불가 행은 회색 배경 + 오른쪽에 이유 글자(잠김·미보유·비어 있음) |
| 스위치 | `Switch`(켜짐/꺼짐 두 상태, `role=switch`) | `TdsSwitch`. 행 전체를 눌러 토글한다 |
| 버튼 | `Button`: `fill`(주요 행동), `weak`(보조 행동), `disabled` | `TdsButton`. 듣기·초기화는 weak, 뽑기는 fill(비활성) |
| 닫기 | 딤 바깥 탭으로 닫기를 권장 | 바깥 탭으로 닫기 유지 + X 버튼(사용자 흐름 문서 요구) |

### TDS 문서에 값이 없어 프로젝트가 정한 값 (`TdsProjectValues`)

이 값들은 "TDS 값"이 아니다. TDS 정식 값이 확인되면 바꾼다.

| 항목 | 프로젝트 값 | 이유 |
| --- | --- | --- |
| 시트 모서리 반경 | 20dp | BottomSheet 문서에 반경이 없다 |
| 버튼·행 모서리 반경 | 14dp | Button 문서에 반경이 없다 |
| 버튼·행 최소 높이 | 52dp | 차량 화면 터치 규칙이 TDS 기본 행 높이보다 우선한다 |
| 글자 배율 | TDS 크기 × 1.25 | TDS 크기는 폰 기준이라 160dpi 2560x1440 차 화면에서 멀리서 읽히게 키운다 |
| 다크 모드 색 | grey 스케일을 뒤집은 파생값(배경 grey900, 표면 grey800) | TDS 색 문서에 다크 값이 없다 |
| 스위치 크기·꺼짐 트랙(grey300) | Material 기본 크기, grey300 | Switch 문서에 크기·색이 없다 |
| primary 색 | TDS blue700(기본 blue500 대신) | 흰 글자 대비 4.5:1 확보 (아래 "대비") |
| 딤 | 사용하지 않음 | TDS는 딤이 기본이지만 딤 색·투명도 값이 없고, 지도 위 오버레이라 뒤 화면을 가리지 않는다 |

### 차량 안전 규칙과의 관계

- 주행 중에는 메뉴와 시트를 즉시 숨긴다(기존 규칙 그대로). 위 TDS 적용은 정차 중 UI에만 해당한다.
- 상태는 색만으로 전달하지 않는다. 장착 중·보유·잠김은 항상 글자를 함께 보인다.
- TDS의 파란색은 차량 시스템 의미 색(경고·규제·주행)과 별개로 이 시트 안에서만 주요 행동·켜짐에 쓴다. 안전 경고에는 쓰지 않는다.

### 대비 (Pleos UI 디자인 가이드: 글자·아이콘 4.5:1 이상)

TDS 문서에는 대비 기준이 없고 Pleos 가이드에는 있다. TDS 토큰을 그대로 쓰면 못 미치는 조합은 **같은 TDS 토큰 중 더 진한 값**으로 바꿨다.

| 조합 | TDS 기본 | 대비 | 앱에서 쓴 값 | 대비 |
| --- | --- | --- | --- | --- |
| 장착 중 글자 | blue500 / blue50 | 3.31:1 | blue800 / blue50 | 5.87:1 |
| 채움 버튼 글자 | 흰 / blue500 | 3.71:1 | 흰 / blue700 | 5.41:1 |
| 비활성 행·상태 글자 | grey600 / grey100 | 4.19:1 | grey700 / grey100 | 6.45:1 |
| 보조 글자(설명·구역 제목) | grey600 / 흰 | 4.62:1 | 그대로 | 4.62:1 |
| 본문 | grey900 / 흰 | 16.56:1 | 그대로 | 16.56:1 |

스위치 트랙(blue500 / 흰)은 글자가 아닌 UI 요소라 3:1 기준이고, 3.7:1이라 그대로 쓴다. 다크 모드 값은 파생값이라 같은 기준으로 계산했을 때
grey300 / grey800 = 7.51:1, 흰에 가까운 본문 / grey800 = 10.52:1이다(비활성 행은 grey300 / grey700 ≈ 4.6:1로 빠듯하다).
